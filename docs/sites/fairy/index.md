# Fairy Site

Fairy is a Kubernetes site. These public pages describe reusable operating
patterns; the current physical inventory and site configuration live in private
operations documentation.

## Site documentation

Keep rack elevations, hardware models, device counts, port assignments and power
feeds in the private inventory. Record changes there when equipment moves or is
replaced. Use that inventory when planning maintenance or recovery.

The public documentation does not provide a current rack elevation or an
addressing plan. Historical diagrams and hardware tables have been retired.
